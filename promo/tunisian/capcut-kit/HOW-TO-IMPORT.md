# Importing into CapCut

Every file is exactly 47.8 s long and starts at 0:00, so they line up when stacked.

## Option A: just tweak the finished video
Import `novi-ai-promo-tn-final.mp4` and edit it like any clip.

## Option B: full control over the sound (recommended)
1. Open CapCut, tap **New project**, and import `video-no-audio.mp4`.
2. Tap **Audio → Extracted / Import audio** (on desktop, **Import → Media**). Add `voice.wav`, `music.wav` and `sfx.wav`.
3. Drag each one to the very start of the timeline (0:00), on its own track.
4. Now you can change each one separately: the voice volume, the music (or replace it with a CapCut track or trending sound), and the sound effects.
   - Tip: if you keep `music.wav`, turn it down to about 40–50% while you're speaking. You can also use CapCut's **Auto-ducking** on the music track.

## Subtitles
- **CapCut desktop:** **Captions → Import captions**, then choose `captions-tn.srt`. The lines are timed to your voice.
- **Phone app:** use **Captions → Auto captions**, or copy the lines from the .srt file.
